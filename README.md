# LLVM course

- [HW1](HW1) — визуализация двумерного уравнения теплопроводности (SDL) и оптимизированный LLVM IR
- [HW2](HW2) — Pass для трассировки использования IR-инструкций (User <- Operand) и статистика частых паттернов
- [HW3](HW3) — IR генератор логического модуля (IRBuilder) и запуск в ExecutionEngine с пробросом графических функций
- [HW4](HW4) — своя система команд, приложение на ассемблере и ASM2IR генератор (эмулирующие вызовы, чистый IR, симуляция)
