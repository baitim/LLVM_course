# Своя система команд, ASM и ASM2IR генератор

Приложение из HW1 (уравнение теплопроводности) переписано на собственную систему команд и запускается тремя способами.

## Файлы
- [ISA.md](ISA.md) — описание системы команд и её связь со статистикой из HW2 и LLVM IR (задание 1)
- [app.s](app.s) — приложение на ассемблере этой системы команд (задание 2)
- [asm2ir.cpp](asm2ir.cpp) — генератор: читает ассемблер и запускает его в одном из трёх режимов
- [test/check_backend.c](test/check_backend.c) — замена `sim.c` для тестов: вместо окна считает хеш всех пикселей
- `../HW1/sim.c`, `../HW1/sim.h`, `../HW1/start.c` — графический интерфейс

## Режимы
```
./asm2ir <sim|ext|full> app.s [dump.ll]
```
| Режим | Что делает | Задание |
|---|---|---|
| `ext` | Строит IR, в котором каждая команда, кроме команд потока управления, — вызов функции `do_<ИМЯ>`, эмулирующей её. Переходы — настоящие инструкции IR. Запускается в `ExecutionEngine`. | 3 |
| `full` | Строит IR, в котором каждая команда заменена своим набором инструкций LLVM IR. Регистры и память лежат в глобальных массивах модуля. Запускается в `ExecutionEngine`. | 4 |
| `sim` | Интерпретатор без IR: команды выполняются теми же функциями `do_<ИМЯ>`. | 5* |

Необязательный третий аргумент — файл, куда записать сгенерированный IR (для `ext` и `full`). Примеры: `make app_ext.ll app_full.ll`.

Семантика каждой команды записана один раз в функциях `do_<ИМЯ>` в начале `asm2ir.cpp`; `sim` и `ext` используют их, а `full` строит те же действия из инструкций IR.

## Сборка и запуск
```
sudo apt install clang llvm llvm-dev libsdl2-dev
make
./asm2ir full app.s
```
Для другой версии LLVM: `make CC=clang-15 CXX=clang++-15 LLVM_CONFIG=llvm-config-15`.

## Проверка
```
make check              # 150 кадров
make check FRAMES=10
```
Собираются приложение на C из HW1 и `asm2ir` с тестовым интерфейсом, который считает хеш всех пикселей. Запускаются C-версия и три режима, хеши должны совпасть:
```
C app (HW1): frames 150 hash 229f2c2bfe23021b
sim: frames 150 hash 229f2c2bfe23021b
ext: frames 150 hash 229f2c2bfe23021b
full: frames 150 hash 229f2c2bfe23021b
all equal
```
Генератор случайных чисел один и тот же, поэтому совпадают и случайные начальные положения источников, и вспышки. 150 кадров нужно, чтобы источники и вспышки успели дойти до границ поля: на 40 кадрах ошибка в проверке правой границы ещё не видна.

Время 20 кадров (интерфейс без окна, 0,02 с у C-версии):

| Режим | Время |
|---|---|
| `sim` | 0,68 с |
| `ext` | 0,12 с |
| `full` | 0,04 с |
